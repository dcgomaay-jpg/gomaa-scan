# Gomaa Scan

تطبيق PWA لمسح المستندات ومعالجتها محليًا باستخدام JavaScript، دون حساب مستخدم أو رفع صور إلى خادم. ملفات التطبيق كاملة داخل هذا المجلد؛ لا يحتاج npm أو عملية build.

## هيكل الملفات

```text
index.html             شاشات التطبيق والنوافذ والقوالب
style.css              التصميم، Cairo، RTL والوضع الداكن
app.js                 الكاميرا، OpenCV، الفلاتر، IndexedDB، PDF وOCR
sw.js                  ملفات الأوفلاين وإدارة الكاش
manifest.json          التثبيت والاسم والأيقونات
icons/logo.svg         اللوجو الأصلي
icons/icon-192.png      أيقونة تثبيت 192 بكسل
icons/icon-512.png      أيقونة 512 بكسل، مناسبة للقص بأشكال مختلفة
icons/apple-touch-icon.png  أيقونة آيفون 180 بكسل
generate-icons.html    أداة إعادة توليد الأيقونات دون مكتبات
.nojekyll              تعطيل Jekyll عند استخدام GitHub Pages
README.md              هذا الدليل
```

## التشغيل أول مرة

1. افتح التطبيق من رابط HTTPS، أو من خادم محلي على localhost. فتح index.html مباشرة بصيغة file:// لا يشغّل الكاميرا وService Worker بشكل مناسب. الكاميرا تتطلب إذن المستخدم وسياقًا آمنًا. [توثيق getUserMedia](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia).
2. من الإعدادات اضغط «تنزيل ملفات الأوفلاين»، وانتظر ظهور رسالة اكتمال التجهيز. التحميل يشمل OpenCV، jsPDF، Tesseract، ملفات WASM، بيانات العربي والإنجليزي، والخط. قد يحتاج اتصالًا جيدًا وعشرات الميجابايت.
3. امنح الكاميرا إذن الاستخدام عند فتح تبويب المسح، أو اختر الصور من المعرض. الكاميرا الخلفية هي الاختيار المفضّل؛ المتصفح يحدد الكاميرا المتاحة فعليًا.
4. راجع الزوايا، ثم صحح المنظور، اختر الفلتر واضبط السطوع والتباين، ثم اعتمد الصفحة.
5. أضف صفحات أخرى أو احفظ المستند. يتم إنشاء الاسم الافتراضي حسب توقيت الجهاز وقت فتح نافذة الحفظ: GomaaScan_YYYY-MM-DD_HH-mm. عند تكرار الاسم يضاف رقم تلقائيًا.

## المسح والمكتبة

- اكتشاف الحواف يحلل صورة مصغرة بطول أقصى 420 بكسل كل نحو 280 مللي ثانية، ويصحح منظور الصورة بعد التأكيد. الالتقاط التلقائي يحتاج ثبات الزوايا لمدة ثانية تقريبًا.
- تعديل الزوايا يدعم اللمس والتكبير أثناء السحب، والأسهم في لوحة المفاتيح؛ Shift مع الأسهم يعطي خطوة أكبر.
- الفلاتر: Original، Magic Color، Black & White، Grayscale، Lighten، Remove Shadows. إزالة الظلال تحسين تقريبي وقد تغيّر ألوان الصور أو التفاصيل الداكنة.
- رفع أكثر من صورة يعرض كل صورة بالترتيب للتعديل، ثم يجمع الصفحات في المستند نفسه.
- PDF يضم كل الصفحات. JPG متعدد الصفحات يُحمّل ويُشارك كصور منفصلة بأرقام متسلسلة؛ لا توجد صيغة JPG متعددة الصفحات.
- اسحب مقبض الصفحة لإعادة ترتيبها أو استخدم تقديم/تأخير. عند تعديل مستند محفوظ اضغط «حفظ التغييرات» قبل الخروج.
- المكتبة تدعم البحث، الترتيب، عرض الشبكة أو القائمة، التسمية والحذف والتحديد المتعدد.
- المشاركة تستخدم Web Share عندما يدعم المتصفح مشاركة الملفات. البديل هو التحميل. عند تجهيز ملف لم يسبق تجهيزه قد يطلب التطبيق ضغطة مشاركة ثانية للحفاظ على إذن المشاركة المرتبط بضغطة المستخدم.
- OCR يعمل على صفحة محددة أو كل الصفحات بالعربي والإنجليزي. المعالجة على الجهاز؛ راجع النتيجة قبل نسخها، خصوصًا الكتابة اليدوية والصور غير الواضحة.
- الصور تُصغّر لطول أقصى 2400 بكسل للحفاظ على الذاكرة. خيارات الضغط تغيّر دقة وجودة ملفات التصدير. النسخ الأصلية المعدلة تُحفظ كذلك لتعديل ترتيب الصفحات لاحقًا.

## الأيقونات

الأيقونات جاهزة. لإعادة توليدها افتح generate-icons.html في المتصفح واضغط «توليد الأيقونات»، ثم نزّل الروابط الثلاثة واحفظها داخل icons بالأسماء نفسها. الأداة ترسم نفس مسار حرف G الموجود في logo.svg على خلفية زرقاء. مقاسات أندرويد 192 و512، وآيفون 180. خلفية PNG ممتدة حتى حواف الصورة وحرف G في المنطقة المركزية؛ نظام الهاتف يرسم الزوايا أو الشكل المناسب.

## النشر على GitHub Pages

1. أنشئ مستودعًا عامًا باسم gomaa-scan في GitHub. المستودعات العامة تدعم Pages ضمن GitHub Free.
2. ارفع محتويات هذا المجلد إلى جذر المستودع بحيث يوجد index.html مباشرة بجوار app.js وsw.js، مع مجلد icons.
3. افتح Settings ثم Pages. اختر Deploy from a branch، ثم فرع main ومجلد /(root)، واضغط Save.
4. انتظر اكتمال النشر وافتح الرابط الذي يظهر في Pages. للمستودع العادي يكون شكله https://USERNAME.github.io/gomaa-scan/.
5. المسارات في manifest وService Worker نسبية، ولذلك تعمل تحت مجلد المستودع.
6. عند تحديث التطبيق غيّر VERSION في sw.js من v1 إلى v2 مثلًا، ثم ارفع الملفات المعدلة. الكاش القديم الخاص بالواجهة يُستبدل؛ مستندات IndexedDB تبقى.

[تعليمات GitHub Pages الرسمية](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site).

## النشر على Netlify

1. فك ضغط المشروع، وسجّل دخولك إلى Netlify.
2. استخدم خيار النشر اليدوي بالسحب والإفلات واسحب المجلد الذي يحتوي index.html مباشرة، وليس مجلدًا أعلى منه.
3. لا توجد أوامر build ولا فريمورك. عند ربط Git اختر مجلد النشر الذي توجد به الملفات واترك أمر build فارغًا.
4. افتح رابط HTTPS الناتج، ثم جهّز الأوفلاين من الإعدادات. راجع حدود الخطة المجانية المتاحة في حسابك وقت النشر.

[النشر اليدوي في Netlify](https://docs.netlify.com/deploy/create-deploys/#drag-and-drop).

## التثبيت على أندرويد

افتح رابط HTTPS في Chrome أو متصفح يدعم تثبيت PWA. اضغط زر التثبيت داخل التطبيق إذا ظهر، أو قائمة المتصفح ثم «تثبيت التطبيق»/«إضافة إلى الشاشة الرئيسية». اسم القائمة يختلف بحسب المتصفح. بعد التثبيت افتحه من أيقونة Gomaa Scan.

## التثبيت على آيفون

افتح الرابط في Safari، ثم مشاركة، ثم «إضافة إلى الشاشة الرئيسية»، وأكّد الاسم. في الإصدارات التي تعرض خيار «فتح كتطبيق ويب» فعّله. [دليل Apple](https://support.apple.com/guide/iphone/bookmark-a-website-iph42ab2f3a7/ios).

## القيود المعروفة

- الفلاش يعتمد على الجهاز والكاميرا والمتصفح. التطبيق يفحص getCapabilities().torch ويخفي الزر عند غياب الدعم؛ لا يُفترض أنه يعمل على كل أجهزة آيفون. [إمكانات مسارات الوسائط](https://developer.mozilla.org/en-US/docs/Web/API/MediaStreamTrack/getCapabilities).
- القوالب والمكتبات وبيانات OCR تحتاج تحميلًا أوليًا. اكتمال التخزين المحلي هو شرط تشغيل تلك المميزات دون إنترنت. تثبيت التطبيق على الهاتف قد يستخدم مساحة تخزين مختلفة عن جلسة المتصفح؛ جهّز الأوفلاين من التطبيق المثبت نفسه.
- OCR قد يكون بطيئًا على الهواتف محدودة الذاكرة، وخاصة المستندات الطويلة. يمكن إيقافه من النافذة.
- طلب التخزين الدائم لا يضمن موافقة المتصفح، ولا يمنع المستخدم من مسح بيانات الموقع. تنزيل نسخ احتياطية ضروري للمستندات المهمة. [StorageManager.persist](https://developer.mozilla.org/en-US/docs/Web/API/StorageManager/persist).
- تغيير المتصفح أو الجهاز أو نطاق الاستضافة لا ينقل المستندات؛ حفظها مرتبط بالموقع داخل المتصفح المستخدم. الوضع الخاص قد يمنع التخزين أو يحذفه عند إغلاق الجلسة.
- تحميل عدة JPG قد يحتاج السماح بتحميل ملفات متعددة. المشاركة أو Clipboard قد تكون محدودة في بعض المتصفحات؛ توجد بدائل تحميل وتحديد النص للنسخ اليدوي.

## المكتبات المثبّتة بإصدارات محددة

OpenCV.js 4.12.0-release.1 عبر حزمة TechStark، jsPDF 4.2.1، Tesseract.js 6.0.1، tesseract.js-core 6.0.0، Cairo 5.3.0، وبيانات OCR من مسار 4.0.0. الروابط في app.js وsw.js؛ عند تغيير أي إصدار يجب تحديثهما معًا وتغيير VERSION في Service Worker. ملف OpenCV يتضمن WASM داخله، وملفات WASM الخاصة بـTesseract تُخزّن منفصلة.
